# 工程合同法务审核系统提示词

> **Engineering Contract Legal Review System Prompt**

## 📋 项目简介

本项目提供一套**优化完整版**的工程合同法务审核系统提示词（System Prompt），可直接用于 AI 大语言模型（如 ChatGPT、Claude、通义千问等），使其化身为一名具有十五年以上执业经验的建设工程领域高级法务总监，对工程合同进行全面、专业、可落地的法律审查。

## ✨ 核心特性

- **九阶段全流程审查**：从合同定性、整体扫描、逐条审查到法务行动清单，覆盖合同审查全生命周期
- **十一条核心原则**：合法性、我方利益优先、司法可执行、商业合理、风险比例等原则相互制衡
- **八条红线底线**：确保生成的替换条文经得起司法检验，不触碰法律强制性规定
- **工程专项模块**：涵盖施工合同、EPC总承包、勘察设计、监理、分包等多种工程合同类型
- **结构化风险评分**：六维度加权评分体系（0-100分），量化合同风险等级
- **法条时效核验**：内置法条版本标注与核验提示机制，防范引用过时法规
- **数值属性标注**：区分【法定强制标准】与【行业惯例参考值】，避免混淆

## 🚀 使用方法

### 方式一：直接复制使用

1. 打开 [`prompts/engineering-contract-review.md`](prompts/engineering-contract-review.md)
2. 复制全部内容
3. 粘贴到 AI 对话工具的 System Prompt / 系统提示词 设置中
4. 在对话中提交需要审查的工程合同文本即可

### 方式二：API 调用

```python
import openai

# 读取提示词
with open("prompts/engineering-contract-review.md", "r") as f:
    system_prompt = f.read()

# 调用 API
response = openai.ChatCompletion.create(
    model="gpt-4",
    messages=[
        {"role": "system", "content": system_prompt},
        {"role": "user", "content": "请审查以下工程合同：\n\n[粘贴合同文本]"}
    ]
)
```

## 📖 审查流程概览

| 阶段 | 内容 | 说明 |
|------|------|------|
| 阶段一 | 合同法律定性与前置审查 | 定性、格式合同判断、主体资格审查 |
| 阶段二 | 合同整体扫描 | 基础信息表、整体风险评级 |
| 阶段三 | 条款结构图 | 全条款风险标注一览 |
| 阶段四 | 逐条深度审查 | 分级颗粒度分析（P0-P3） |
| 阶段五 | 缺失条款检测 | 通用+工程专项+国企专项 |
| 阶段六 | 风险矩阵与评分 | 六维度加权评分 |
| 阶段七 | 合同机制穿透分析 | 激励、信息、责任、时间四维度 |
| 阶段八 | 数字与税务专项审查 | 金额、日期、比例、税务 |
| 阶段九 | 法务行动清单与最终建议 | 谈判策略、签署建议 |
