# 鉴史决策 · 人生抉择推演技能库

![Cases](https://img.shields.io/badge/案例-29（史记19＋通鉴10）-8B1A1A)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue)](LICENSE)

> 以《史记》《资治通鉴》为母本的结构化历史决策案例库 + 检索推演引擎。
> 输入你正在面对的人生抉择，检索**场景内核相似**的历史抉择案例，拆解古人当时的
> 处境、可选项、判断依据与最终结果，附**原文出处**，最后输出**规律启发**与**风险提醒**。

> 📌 说明：需求中的《政治通鉴》按惯例理解为《资治通鉴》（司马光）。如需替换为其他底本，案例库结构完全兼容，直接按 schema 增补即可。

---

## 这个库解决什么问题

人生的大多数关键抉择——**去留、站队、忍让、决断、用人、押注、进谏、退场**——
在两千年的信史里都被反复演练过，而且**结果已经揭晓**。

本库把这些案例做成机器可检索的结构化数据，让你在做决定之前，先看看
「和你处境同构的那个古人，当时怎么想、怎么选、后来怎么样了」。


## 快速开始

```bash
# 1. 描述你的处境，获取推演报告
python3 scripts/advisor.py "公司被大厂收购，老板让我表态站队，新领导和旧领导不和"

# 2. 按场景内核浏览案例
python3 scripts/advisor.py --kernel 进退去留

# 3. 列出全部内核与案例
python3 scripts/advisor.py --list

# 4. 输出 markdown 报告文件
python3 scripts/advisor.py "要不要拿全部积蓄创业" -o report.md
```

## 案例的拆解结构（每案八段式）

| 字段 | 说明 |
|---|---|
| `kernel` | 场景内核——这个抉择的**原型**是什么（如「进退去留」「高风险押注」） |
| `situation` | 当时局面：约束、筹码、时间窗口 |
| `options` | 当事人当时**真实拥有的选项**（含各选项的预期收益/风险） |
| `choice` | 实际选择 |
| `reasoning` | 当事人的判断依据（明说的 + 可推知的） |
| `outcome` | 结果：短期结果 + 终局 |
| `original_text` | 原文引文 + 精确出处（书名·卷/篇名） |
| `insight` / `risks` | 规律启发 + 风险提醒（迁移到现代场景时的适用边界） |

## 场景内核（13 类抉择原型）

忍辱蓄势 · 进退去留 · 站队择主 · 关键决断 · 用人识人 · 高风险押注 ·
信息采信 · 过度自信 · 纳谏倾听 · 顾全大局 · 变革树敌 · 功高震主 · 利益与底线

详见 [docs/decision-kernels.md](docs/decision-kernels.md)。

## 使用于 LLM / Agent

把 [SKILL.md](SKILL.md) 与 `cases/` 目录一并提供给任意 LLM Agent，
即可让其按本库的八段式框架为用户做人生抉择推演。

## 免责与边界

- 历史案例是**参照系**而非答案。古今的制度环境、风险结构、退出机制差异巨大，`risks` 字段专门标注迁移边界。
- 引文以中华书局点校本为参照凭记忆录入，用于研究前请核对原书。
- 本库不构成任何法律、投资、医疗建议。

## 贡献新案例

详见 [CONTRIBUTING.md](CONTRIBUTING.md)。简要流程：

1. 选案（抉择时刻明确、选项真实存在过、结果可追踪到终局、有可引原文）；
2. 按 `schema/case.schema.json` 编写 JSON，放入 `cases/`（文件名 = id）；
3. **引文逐字核对原书**（中华书局点校本），出处精确到卷/篇；
4. 本地运行 `python3 scripts/validate.py`，全部通过后提交 PR；
5. CI（GitHub Actions）会自动重跑校验 + 引擎冒烟测试。
