# 砾鉴

**以《史记》《资治通鉴》为砾，打磨当下抉择。**

史为镜，非卜筮。本仓库把两部书里的关键人生/政治抉择，做成可检索的结构化技能：先抽取你处境的**场景内核**，再取出纹理相似的历史砾石，拆解故人当时的选项、判断与结果，出示原文出处，最后给出规律启发与风险提醒。

它不是算命，不是厚黑教战，也不是替你做决定。

## 做什么

1. 把当下两难写成处境（或点一条现成的问）。
2. 引擎按 **七维内核** 与 **十八种纹理** 检索，而不是按故事外形相似。
3. 每粒砾石给出：处境、当时选项、选择与判断、近/远结果与对照人物、原文与今译、映射、**此砾不可妄用**。
4. 跨砾抽出鉴语：规律启发 + 风险提醒。

范蠡对照文种，张良对照韩信，曹操对照袁绍。单例会骗人，对照才是砾。

## 三种用法

### 网页

```bash
python3 -m http.server 8080
```

打开 `http://localhost:8080`。问策，取砾。

### 命令行

```bash
python3 ljian.py "我立了大功，老板开始客气而疏远，期权没兑现，要不要走"
python3 ljian.py --list
python3 ljian.py -n 2 --json "两个团队抢我，一个有资源一个同心"
```

无需第三方依赖，Python 3.8+ 即可。

### 给模型用的技能

把 [`skill/SKILL.md`](skill/SKILL.md) 接到你的 agent / Claude Skill / 系统提示里。模型按七维收境、按纹理取砾、按固定模板输出，并被禁止把高平陵、玄武门写成操作手册。案例库在 `data/`。

## 检索在比什么

不比「有没有宴会」「是不是战国」。比的是：

- 功已经大到使上位者不安了吗？
- 窗口还开着吗？
- 评价函数还用得上你的才能吗？
- 最坏结果可逆吗？
- 你在优化被讲述，还是优化下一局？

因此「期权没兑现、老板开始疏远」可以取到范蠡，尽管你并不在会稽。

## 不是什么

- 不预测你「会不会像韩信」。
- 不提供害人、政变、违法的步骤。
- 不把司马迁的笔法或司马光的臣光曰当成录像。
- 不替代你做决定。石用来打磨，手还是你的。
