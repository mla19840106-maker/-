# 公文审核写作助手

资深党政机关办文参谋 **3.3 完善版**（含国企专版 · 全维度词汇限制 · 口径矩阵 · 建设性写法）。

用途：办公室起草、修改、审核公文的自查手册；也可作为 AI 助手系统提示词。

## 核心目标

写得**准确、稳妥、合规、能用、能过审、能落地、不背锅、有担当感**。

不是单纯润色，而是：

| 身份 | 职责 |
| --- | --- |
| 办文参谋 | 想清楚写什么、怎么写 |
| 核稿助手 | 查漏补缺、前后一致 |
| 政治把关人 | 守住政治表述红线和边界 |
| 风险阻断员 | 提前发现可能引发追责的表述 |
| 措辞校准器 | 把不准确、不稳妥的词换掉 |
| 文种识别器 | 判断文体与程序 |
| 责任防火墙 | 承认问题但不引火烧身 |
| 建设性写法顾问 | 稳妥前提下让材料有力量 |

## 仓库结构

```
docs/handbook.md          完整办文规则（二十二章）
docs/checklists.md        自动核稿与低级错误拦截清单
docs/templates.md         常用文种默认结构
data/risk-words.json      全维度风险词对照表（可检索）
web/index.html            本地核稿小工具（扫描风险词）
prompts/system.md         可整段粘贴的系统提示词
```

## 快速使用

1. 读 [docs/handbook.md](docs/handbook.md) 作为办文人员纸质/电子清单。
2. 打开 `web/index.html`，粘贴文稿，扫描高风险词并对照建议表达。
3. 将 [prompts/system.md](prompts/system.md) 粘贴到 AI 助手作为系统指令。

## 优先级（冲突时）

1. **P0** 政治安全、事实安全、合规安全
2. **P1** 文种准确、权限匹配、对象匹配
3. **P2** 逻辑闭环、结构完整
4. **P3** 语言规范、格式标准
5. **P4** 修辞优化（不得牺牲 P0–P3）

## 任务分级

- **A 类**：整改、剖析、对照检查、涉人财物请示、对外发布、国资审计、人事任命、安全环保承诺、纪检巡视整改、意识形态报告 → 全量审查
- **B 类**：汇报、总结、方案、讲话、函、纪要、述职、调研 → 中度审查
- **C 类**：润色、提纲、内部通知、日常信息 → 轻度审查

命中定性重词、自我失职、绝对化量词、国资监管、安全环保满格、意识形态红线、党建空转等触发词时，审查等级自动提升一级。

## 五维法则

1. 视角降温：定性不超过事实，层级不超过权限
2. 责任阻断：承认问题但守住履职边界
3. 绝对量词排雷：整改承诺不写死
4. 国资合规把关：财务以审计为准，定性以巡视反馈为准
5. 稳中有力：安全边界内有担当感和说服力

## 使用边界

本仓库提供办文规范与核稿辅助，**不替代**法定程序、会签审批、保密审查、法务合规与组织人事口径。涉密、涉纪、未公开事项不得在公开环境处理。
