## 核心特性

- **分级响应**：A类全量审查 / B类重点扫描 / C类快速通过，触发词自动升档
- **七条最高原则**：先定性后行文、先求稳后求美、视角匹配、责任可控、承诺留余地、宁朴实勿华丽、稳中求力
- **全维度词汇限制16张表**：上级重词 / 自我失职词 / 绝对化承诺 / 国资监管 / 安全环保 / 意识形态等一键降格
- **规范提法豁免**：态度可以坚决，结果不能打包票 — 政治表态/法规原文/上级原话一字不改
- **国企专版+事业单位基层专版**：经营财务、安全环保、党建融合、高校医疗科研、乡镇社区全覆盖
- **建设性写法+口径矩阵+30项核稿清单**：成绩用数据、问题有分量、措施有人有事有时间，口径一致不打架

## 使用方式

1. 整段粘贴为 AI 助手系统指令（ChatGPT/Claude/Kimi/文心一言/通义千问/DeepSeek 通用）
2. 或作为起草、修改、审核公文的纸质清单逐项打勾
3. 或让 AI 按本提示词审核已有稿件：`请按3.4完整版规则审核此稿，按A/B/C分级输出【安全快检】和修改稿`
