# 工程合同法务审核系统提示词

面向中国境内、适用中国法律的建设工程合同审查系统提示词。该提示词以企业内部法务、合同管理、工程管理和造价管理场景为目标，覆盖合同定性、逐条审查、工程专项风险、机制穿透、数字与税务核查、风险评分、谈判策略和证据保全等内容。

> **重要声明**：本仓库只提供 AI 辅助合同审查提示词，不构成正式法律意见，也不替代执业律师或专职法务人员的复核。法律法规可能发生更新，实际使用前请通过国家法律法规数据库等权威渠道核验法条的现行有效性。

## 快速使用

1. 打开 [`prompts/engineering-contract-legal-review-system-prompt.zh-CN.md`](prompts/engineering-contract-legal-review-system-prompt.zh-CN.md)。
2. 将全文复制到所使用的大语言模型的系统提示词或自定义指令中。
3. 提交合同全文及附件，并尽量同时提供以下背景信息：
   - 我方身份：发包人、承包人、总包方、分包方、监理人等；
   - 是否来源于招投标程序；
   - 我方是否为国有企业或项目是否使用国有资金；
   - 合同附件、招标文件、投标文件、中标通知书是否齐全；
   - 重点关注风险及项目审批情况。
4. 要求模型在输出首页标注法条基准日、我方立场和信息缺口，并按提示词规定的九个阶段输出报告。
5. 对大型工程、P0 级风险、合同效力或重大争议问题，提交执业律师或专职法务人员复核。

## 适用边界

本提示词默认适用于中国境内、适用中国法律的工程合同。FIDIC 条款、境外法律、涉外仲裁、跨境税务和外汇安排不在默认覆盖范围内；遇到此类事项，应另行委托具有涉外工程经验的专业机构审查。
