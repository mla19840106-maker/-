# 砾鉴方法论

## 为何叫砾

河床里的石头被水打磨，棱角还在，纹理各异。历史里每一次不可逆的选择，也沉淀成这样的石。我们不把史书当故事会，而当成一袋可以上手的砾。

取砾不是找「情节像不像」。鸿门宴的外形是宴会，内核是：已入刀俎之席，实力未够，目标只剩活着离开。用户若在谈一场不友善的约谈，外形毫无宴会，纹理却可能同纹。

## 七维

| 维 | 要问的话 |
| --- | --- |
| 势 | 力量对比与趋势朝哪边走 |
| 时 | 窗口开着、将开，还是已经关上 |
| 位 | 你在结构里是主、客、功臣，还是骑墙 |
| 义 | 靠名分、恩情还是利害来说服自己 |
| 信 | 承诺、盟约、人情还能否托付 |
| 退 | 有无退路，退了还能不能回来 |
| 险 | 最坏是丢脸、失利，还是毁灭、不可逆 |

七维是提问框架，不是评分游戏。有两维尖锐就够取砾。

## 纹理

纹理是比七维更贴地的「抉择基因型」。功高震主与进退时机经常伴生，但不是同一件事：前者说威胁结构，后者说窗口。检索时用纹理加权，再用关键词与场景内核的字面重叠作辅助。

## 对照

单粒砾会骗人。范蠡必须对照文种，张良必须对照韩信，曹操必须对照袁绍。对照不是道德评优，是把「另一条当时可见的路」留在桌上。

## 史源

- 《史记》：纪传，人物与命运，司马迁有自己的褒贬与文学。
- 《资治通鉴》：编年资治，司马光有「臣光曰」。开卷智伯，问的是才与德、欲与礼。

二者都经过选择、剪裁、事后聪明。活下来的人被写得更清楚，失败者的合理选项常常失传。砾鉴把这一点写进风险，而不是假装库是全样本。

## 不是什么

- 不是卜筮，不预测你「会不会像韩信」。
- 不是厚黑学，不把高平陵、玄武门写成操作步骤。
- 不是心灵鸡汤，不把身退、隐忍、兼听说成正确人格。
- 不是替代决策。石用来打磨，手还是你的。

## 误用边界

每粒砾都有「此砾不可妄用」。范蠡不能证明一遇压力就辞职；蒯通不能证明有能力就该造反；魏征不能证明在暴怒的老板面前当众顶撞。结构相似是取砾理由，条件缺失是停手理由。
