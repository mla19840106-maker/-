# 整理与修订说明

## 3.4 · GitHub 整理版 — 2026-09-07

基于本次提供的《资深党政机关办文参谋 3.4 完整版》整理。本次主要目标是建立可阅读、可复制、可核查、可维护的提示词仓库，不是生成某份具体公文或开发自动发文系统。

**本仓库没有另存一份逐字原文备份。** `prompts/full.md` 是带实质性适用边界修订的完整整理版，不能用于证明原稿逐字内容。以下记录主要修改类别；如需严格逐字比对，应由原文持有人在合规环境提供和保管原始版本。

## 二、实质性修订记录

下列“原稿倾向”是归纳，不作为逐字引文。规范来源和本次有限核验范围见[参考依据](references.md)；本表主要记录提示词设计和风险控制上的修订。

| 序号 | 位置 | 原稿倾向或冲突 | 本版处理及原因 |
| --- | --- | --- | --- |
| 1 | 执行前提、第一章 | 以真实30年任职者身份表述 | 保留经验型写作方法，不声称实际履历、资质或授权 |
| 2 | 总纲、启动 | 以不背锅、不退稿、领导满意等作为保证式终局 | 改为可用、可核、便于审签的目标，不承诺审核结果或免责 |
| 3 | 优先级、冲突处理 | 用户坚持风险词或定制口径可能覆盖全部规则 | 仅允许风格偏好调整；事实、合规、保密及平台上位要求不被覆盖 |
| 4 | 第五章 | 任何任务必须三问，与C类直接出稿冲突 | 读取已知信息，只问影响成稿的缺项；纯格式任务不阻断，急件最少追问 |
| 5 | 第四章 | 只按触发词升级一级，可能把敏感润色留在B类 | 按语义识别，实质涉及A类直接升A；词语命中不自动判错 |
| 6 | 第十一、十二章 | 主要区分态度句与结果句 | 扩展区分态度、义务、批准目标、真实事实、无条件未来保证 |
| 7 | 词汇表、自动核稿 | 全部、每一项、100%、确保等倾向机械降格 | 真实统计与完成状态保留；不缩小任务范围、不延长期限、不削弱义务 |
| 8 | 国资及纪律场景 | 流失→减值、已发生行为→廉洁风险等替换容易改变性质 | 明确不是同义词；已认定按有效原文，未认定写具体行为、线索及真实核查状态 |
| 9 | 基层、人事、舆情 | 强拆→依法搬迁，内定→经组织研究，删帖→阵地管理 | 禁止通过替换制造合规事实；行为、依据、程序与争议如实描述 |
| 10 | 自查、检讨 | 为守住边界，可能把严重问题全部变成薄弱环节 | 责任不夸大也不淡化；正式认定、严重已知事实和报告义务保留 |
| 11 | 引文、锁定口径 | 上级原话一字不改可能被误解为必须复述所有内部内容 | 锁定准确性同时核来源、有效性、授权和使用环境；受限原件线下处理 |
| 12 | 口径矩阵 | 向主管部门的报告默认将问题降一档 | 正式性质和重要事实统一，仅按目的与知悉权限调整详略 |
| 13 | 成绩、排名 | 缺数据写据初步统计，排名不明改位居前列 | 没有依据就待补或删除，不能换词继续作无依据结论 |
| 14 | 财务 | 未审计一律只能写预计 | 区分未经审计实际数、审计数、预算与预测；经确认可用的实际数标真实状态 |
| 15 | 投资、诉讼 | 审批未完改拟投资，未结案只写正在应诉 | 区分审批、支付、实施和不同诉讼阶段；实际已支付或已有判决不得被抹掉 |
| 16 | 文种 | 请示不夹带报告内容，容易误删必要背景 | 区分无关事项与必要事由、情况和依据；报告不得夹请示 |
| 17 | 文种速查 | 以层级概括命令等使用资格，上行意见一概须批转 | 改为核主体、权限、用途及适用程序，不将经验边界当硬性法定限制 |
| 18 | 日期、主送、抄送 | 日期一概签发日，主送个人例外和抄送排序处理过硬 | 日期区分会议通过与签发；主送和例外核适用要求，抄送排序依有效规范及模板 |
| 19 | 纪要、表决 | 原则同意优于完全确定，有弃权可改审议通过 | 会议结论按事实；是否通过依规则和票数，不以柔化代替真实结论 |
| 20 | 数字 | 所有比例加总100%、同指标只能有一个数 | 仅同口径、互斥且穷尽构成项要求加总；时序指标允许不同数，明确时点 |
| 21 | 数字 | 完成率超过100%与超额率易混淆 | 明确完成计划120%对应超额完成20%，核基数、负数和零基数情形 |
| 22 | 标点及语感 | 数值范围、金额分节、简称和常用近义词一律判错 | 区分规范要求、专业体例和风格偏好，不假称概括表覆盖所有标准例外 |
| 23 | 国企治理 | 董事长被写成当然法定代表人，泛用董事长负责制 | 核法律、章程、登记与实际职权，区分董事长个人与董事会 |
| 24 | 职工利益 | 所有方案一律职代会或工会审议通过 | 按事项分别核听取意见、讨论、协商、审议、表决、公示和审批，不伪造程序 |
| 25 | 上市公司 | 禁止一切内部材料提前记载未公告事项 | 区分合法必要知悉的内部办理与对外披露，控制范围与渠道，不将内部材料上传公开服务 |
| 26 | 事业单位 | 不同医疗指标、就业指标、处分、聘用等可直接互换 | 指标和法律概念分别核口径，不能只换名称沿用原数、原结论 |
| 27 | 干部人事 | 未正式发文一概不能出现拟任信息 | 区分有权内部办理、任前公示和未经授权泄露，核相应程序 |
| 28 | 责任与群众工作 | 一律不点名其他部门，客观原因必须居后 | 按事实和报告用途说明责任、因果、时间线；不编造主观过错，不隐去必要责任主体 |
| 29 | 多轮留痕 | 自动继承口径容易被理解为永久记忆 | 仅继承可见上下文，使用版本卡、事实表、锁定原文和新会话交接包 |
| 30 | 输出与禁止 | 提示词用Markdown与公文正文禁Markdown易混淆 | 文档与提示区可用Markdown；生成的普通公文正文纯文本，清单附件按要求用表格 |
