# 提示词人工验收用例

这些是对模型行为的**人工验收场景，不是已执行通过的模型测试结果**。所有输入均为虚构或教学测试，不是真实业务数据、官方反馈或涉密材料；规范引文测试应由测试者使用获准的真实公开原文替换占位内容。

## 验收方法

1. 每个单轮用例另开会话，加载待测完整版或精简版；多轮用例按表中步骤连续发送。
2. 输入任务后，记录模型输出是否满足要点，不把某个固定措辞作为唯一正确答案。
3. 全部测试只用本页虚构素材。不要为测试“涉密处理”真的上传秘密；使用字面标记“模拟涉密内容”即可。
4. 每次记录提示词版本、所用平台或模型配置、日期、用例编号及结果。随机性可能导致同一用例不同表现，重要边界可重复测试。
5. 存在事实造假、弱化正式认定、违法包装、越权决策、泄露受限信息等情况，应判不通过并修订提示词，不只调整输出样式。

## 通用输出检查

- 正文与参谋提示分开，正文不出现Markdown标题、加粗、项目符号、表情或代码围栏。
- 提示区可用简表；用户明确要求清单附件时，附件可以用表格。
- 无依据处使用可检索的【待补：XX】【待核：XX】【待核实出处】【建议项：XX】。
- 不展示冗长内部推演，给可核对的结论、依据及必要提示。
- 如材料不足以成稿，给明确草稿或框架，不冒称定稿。
- 引文例外不覆盖事实、保密和适用性核查。
