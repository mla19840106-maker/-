# 办文任务输入模板

先加载[完整版](../prompts/full.md)或[精简版](../prompts/lite.md)，再复制下方模板填写。不必填满所有项目；已知就填，不确定就保留【待补】。只提供获准在当前平台使用的信息，签发主体可填职务或角色，无需提供不必要的真实姓名。

## 通用模板

```text
【任务】
任务类型：【待补：起草／修改／核查／提纲／缩写／扩写／统一口径】
文种或材料类型：【待补：可请参谋判断】
代表单位及签发层级：【待补：单位类型、层级、签发角色】
报送或讲话对象：【待补：机关、机构或人员范围】
核心目的：【待补：请求批准／报告情况／说明事实／整改／部署／表态】
篇幅、使用时间、是否急件：【待补：要求】
是否对外发布、涉及职工权益或其他敏感事项：【待补：仅说明类别】

【素材使用边界】
仅使用经确认可在当前平台处理的非涉密素材。
不可在当前平台使用的原件和细节不粘贴，由线下合规流程补充。
本稿允许使用的信息范围：【待补：可公开内容或获准使用的脱敏摘要】

【已知事实】
事项和时间线：【待补：事实、时点、资料来源】
数据：【待补：指标、数值、单位、统计期间、分子分母、来源及确认状态】
已有正式结论：【待补：可引用内容、有效性、出处；没有则写无】
已完成事项：【待补：内容、完成日期、验收或凭证状态】
未完成事项：【待补：内容、原因、既定期限、实际进展】

【依据与程序】
适用文件或制度：【待补：名称、版本、已提供的真实文号或公开出处】
已履行程序：【待补：实际研究、征求意见、会签、审批及凭证】
尚待履行程序：【待补：缺项，不得写成已完成】
责任主体和既定时限：【待补：已确认分工与节点；未定事项说明未定】

【不可改动与多轮口径】
锁定原文：【待补：仅限已授权且可在当前环境使用的文字】
锁定内容的来源和使用范围：【待补：出处及边界】
已确认事实、结构和定制口径：【待补：上一轮确认内容；无则写无】
当前版本：【待补：版本或无前稿】
本轮修改范围：【待补：全文／指定章节／仅错字标点】

【原稿或素材】
【待补：粘贴可使用的原稿；没有原稿时写已知要点】

【输出要求】
先识别文种和风险等级，已有信息不重复问。
信息不足标【待补：XX】或【待核：XX】，拟议安排标【建议项：XX】。
不得编造事实、定性、数据、文号、条款、会议、批示、程序和进展。
正文用纯文本及公文序号；提示与正文分开。
只修改指定范围，列必要的关键变更；有明确问题时不要只做措辞美化。
```

## 急件最小模板

```text
这是急件，请按最少追问规则处理。
代表单位、签发层级及对象：【待补】
核心目的：【待补】
篇幅和截止时间：【待补】
已知事实及可用素材：【待补】
不可改的已授权口径：【待补：有则填，无则写无】
请先给可用草稿；缺少事实标待补，不编造数据、依据、程序或进展。
```

## 只核查、不重写

```text
请核查以下材料，不默认重写全文。
文种、签发主体、对象与用途：【待补】
核查重点：【待补：文种／事实／数据／程序／定性／引文／格式】
锁定原文与已确认口径：【待补】
材料：【待补：仅粘贴获准使用的内容】
请按“位置／原文／问题／处理建议／待核依据”列出关键项。
已认定问题不降格，法定义务与真实完成状态不机械削弱。
```

## 提交前自查

- 是否可以在当前平台处理这些信息？脱敏是否经确认，而非仅删除姓名？
- 是否把已知事实、用户主张、正式认定、建议和未知项分开？
- 是否提供数据的时点、范围和确认状态，而不只是一个数？
- 是否区分已履行程序与拟履行程序？
- 是否说明只改某部分，避免不必要的全文重写？

多轮修改请配合[版本与口径留痕模板](revision-log.md)。
